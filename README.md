## Germán Gómez

**Data & BI Developer** · ETL · SQL · Python · Power BI
Bogotá, Colombia (UTC-5) · Open to remote roles

I build the data pipelines and models behind public-policy reporting in Colombia. For 7+ years I've integrated data from local governments into relational databases, automated reporting workflows and delivered BI models used across the country.

### Highlights

- **ETL automation:** pipelines built with n8n, Python and SQL that integrate local-government reports (FUT, SIGO/PAT Dashboard, Excel/CSV) into PostgreSQL, SQL Server and MySQL, saving about 8 hours a week of manual consolidation.
- **BI at national scale:** Power BI models (Power Query, DAX, star and snowflake schemas) used by 1,135 local government entities and internal teams at Colombia's Victims' Unit.
- **Data modeling and governance:** designed the data model of the PAT Dashboard information system and its interoperability with national systems; defined KPIs and their calculation methodology; standardized data from local governments.

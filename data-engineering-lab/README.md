# Data Engineering Lab

**English** · [Español](README.es.md)

Hands-on data engineering work: SQL on PostgreSQL, containerized databases with Docker and Python ingestion jobs. Each folder is self-contained and explains how to run it.

## Contents

| Folder | What it covers |
|---|---|
| [`sql/`](sql/) | Advanced PostgreSQL: window functions, CTEs, upserts and query performance tuning, with commented solutions. |
| [`docker/`](docker/) | A PostgreSQL and pgAdmin stack with Docker Compose, plus a containerized Python job that loads open data from [datos.gov.co](https://www.datos.gov.co). |

## Requirements

- [Docker Desktop](https://docs.docker.com/get-started/)
- Python 3.12
- `psql` (optional, to query the database from the terminal)

# Data Engineering Lab

[English](README.md) · **Español**

Trabajo práctico de ingeniería de datos: SQL sobre PostgreSQL, bases de datos en contenedores con Docker y procesos de ingesta en Python. Cada carpeta es independiente y explica cómo ejecutarla.

## Contenido

| Carpeta | Qué incluye |
|---|---|
| [`sql/`](sql/) | PostgreSQL avanzado: *window functions*, CTE, *upserts* y optimización de consultas, con soluciones comentadas. |
| [`docker/`](docker/) | Un stack de PostgreSQL y pgAdmin con Docker Compose, más un proceso de Python en contenedor que carga datos abiertos de [datos.gov.co](https://www.datos.gov.co). |

## Requisitos

- [Docker Desktop](https://docs.docker.com/get-started/)
- Python 3.12
- `psql` (opcional, para consultar la base desde la terminal)
